# Меню Baritone для Fabric 1.21.11

1. Скачай `route-menu-1.1.0+1.21.11.jar` из репозитория и положи его в папку `mods`.
2. Установи Fabric Loader 0.18.4 или новее, [Fabric API для 1.21.11](https://maven.fabricmc.net/net/fabricmc/fabric-api/fabric-api/0.141.1+1.21.11/) и [Baritone API 1.17.0 для Fabric](https://github.com/cabaletta/baritone/releases/tag/v1.17.0).
3. Введи `/bari` в игровом чате.
